# microbreaks

Take a break. A small Windows tray app that enforces the **20-20-20 eye rule** and **hourly movement breaks** (squats, etc.) during the work day. It sends reminders to your phone via [ntfy](https://ntfy.sh) when you're away or off-hours.

- [SPEC.md](SPEC.md): what we're building and how.
- [STATUS.md](STATUS.md): where we are and what's next.

Built with Tauri 2 (Rust + TypeScript).
